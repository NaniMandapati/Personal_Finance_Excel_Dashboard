# 💰 Personal Finance & Budget Dashboard

An interactive personal finance dashboard built in Microsoft Excel to monitor monthly expenses, track budget utilization, and visualize savings progress.

## 🖥️ Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 📌 Project Overview
This project provides a comprehensive view of personal cash flow by analyzing transaction data across multiple accounts. It features dynamic KPI cards and interactive charts that update instantly based on user selection.

### Key Features
* *Dynamic KPI Cards:* Instant visibility into Total Income, Total Expenses, Net Savings, Savings Rate, and Budget Utilization.
* *Cash Flow Analysis:* Trend lines comparing monthly income versus expenses.
* *Categorized Spending:* Visual breakdowns of expenses by category and payment method.
* *Goal Tracking:* Progress tracking for specific savings goals and account balances.
* *One-Click Refresh:* Automated macro integration to refresh all pivot tables and charts instantly.

## 🛠️ Excel Skills Demonstrated
* *Data Structuring:* Using Excel Tables and calculated columns (Month, Quarter) for scalable data entry.
* *Advanced Aggregation:* Building multi-layered Pivot Tables to summarize complex transaction data.
* *Data Visualization:* Creating Line, Doughnut, Clustered Column, and Waterfall charts.
* *Interactive Filtering:* Connecting Data Slicers across multiple Pivot Tables for a seamless user experience.
* *Basic VBA/Macros:* Implementing a refresh button macro to automate reporting updates.
